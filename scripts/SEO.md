# SEO launch checklist

Technical metadata, sitemap, robots, structured data, and social preview cards are generated by the app. First-page ranking for competitive non-branded queries still depends on indexing, unique content, and reputable links over time.

## Production URL

Set this on Vercel Production:

```
NEXT_PUBLIC_SITE_URL=https://www.onebyoneministries.org
```

Do not use `http://localhost:3000`, a `*.vercel.app` preview host, or the non-www apex as the production canonical URL. Apex requests already redirect to `www`.

Optional verification tokens (HTML tag method):

```
GOOGLE_SITE_VERIFICATION=
BING_SITE_VERIFICATION=
```

Redeploy after adding them.

## Google Search Console

1. Add `https://www.onebyoneministries.org` as a URL-prefix property (or the domain property if DNS verification is available).
2. Paste the Search Console HTML-tag token into `GOOGLE_SITE_VERIFICATION` if you are not using DNS verification.
3. Submit `https://www.onebyoneministries.org/sitemap.xml`.
4. Request indexing for `/`, `/about`, `/projects`, `/stories`, `/donate`, and `/contact`.
5. Confirm coverage for public pages only. `/admin`, `/api`, `/auth`, and `/setup` are disallowed and noindexed.

## Bing Webmaster Tools

1. Import the verified Search Console property, or add the site and use the Bing HTML-tag token as `BING_SITE_VERIFICATION`.
2. Submit the same sitemap URL.

## Social link previews

After deploy, refresh cached previews:

- Facebook Sharing Debugger
- LinkedIn Post Inspector
- X/Twitter Card Validator
- A live WhatsApp, Slack, Discord, or iMessage share of the homepage, donate page, and one published story

Each public page uses a 1200×630 PNG card. If a hero image is uploaded, that photo is the background; otherwise the branded fallback card is used. Story URLs use `/og/stories/[slug]`.

## Local verification

```
npm run check:env
npm run test:seo
```

For a production-canonical check against the current env files:

```
CHECK_PRODUCTION_SEO=1 npm run check:env
```
